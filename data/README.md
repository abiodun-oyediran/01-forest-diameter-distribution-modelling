# Data

## Tabular data

| File | Description | Provenance |
|---|---|---|
| `raw/dbh_sample.csv` | 500 tree diameters (DBH, cm), one column with header `Dbh(cm)` | **Synthetic.** Generated by `scripts/make_sample_data.R` (seed 2026). Not field measurements. |

The synthetic sample has a reverse-J (right-skewed) size structure above a
10 cm threshold plus a small share of large canopy trees. Regenerate it with:

```bash
Rscript scripts/make_sample_data.R
```

Optional environment variables: `DBH_N` (rows, default 500), `DBH_SEED`
(default 2026), `DBH_CSV` (output path).

## Using your own data

Provide a CSV with a single DBH column (centimetres) whose header is `Dbh(cm)`
(`read.csv` reads it as `Dbh.cm.`), then point the pipeline at it:

```bash
DBH_CSV=path/to/your_dbh.csv Rscript run_all.R
```

Rows with missing, non-numeric or non-positive values are dropped by
`R/01_data_cleaning.R` and the number removed is reported.

## GIS / spatial data

None. This repository does not use shapefiles, rasters or any other spatial data.
